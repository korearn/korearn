### 🧪 How I like to build

- **Local-first.** If it can run on my own hardware, it does.
- **Small tools, real problems.** One thing, done well, with a README you can follow.
- **Boring infra, interesting logic.** Linux, Bash, Docker, cron — then the fun part.
